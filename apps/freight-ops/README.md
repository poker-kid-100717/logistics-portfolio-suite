# Freight Ops

Portfolio CRM/operations application focused on customer prioritization and external freight visibility.

## Demonstrates

- Angular 22 recruiter-facing operational dashboard
- .NET 10 minimal API
- explainable account/opportunity scoring
- third-party adapter boundary
- server-side OAuth client credentials
- Alvys Public API Loads Search in optional live mode
- graceful degradation to synthetic portfolio data

The scoring formula is intentionally portfolio-only and is not copied from a professional system.
