# LTL Planner

Portfolio planning application that groups shipment orders onto compatible truck profiles under hard pallet, weight and equipment constraints.

## Demonstrates

- deterministic, explainable planning
- hard constraint enforcement before scoring
- modern Angular 22 planning workspace
- .NET 10 service boundary
- optional read-only Alvys Loads Search
- Yard-facing candidate endpoint
- HMAC-verified, idempotent Yard event ingestion

The planner uses a deliberately understandable best-fit heuristic rather than a copied operational algorithm.
